## 3. Scoring (if comparing options)

Rate 1–5. Weights must sum to 100%.

| Criterion | Weight | Option A | Option B | Option C |
|---|---|---|---|---|
| User value | 30% | | | |
| Business value | 25% | | | |
| Feasibility | 20% | | | |
| Strategic fit | 15% | | | |
| Risk (5 = low risk) | 10% | | | |
| **Weighted total** | 100% | | | |

Scoring supports the discussion; it does not replace it. Record where intuition and scores disagree.
