# Checklists

Each template already ends with **Completion Criteria** for that one document. These checklists cover what no single template can: **checks across documents** and **gates between phases**.

| Checklist | Use it when |
|---|---|
| [Cross-document consistency](cross-document-consistency.md) | Before approving documents together, and at the planning readiness gate |
| [Planning readiness (quick form)](planning-readiness.md) | A one-page version of the gate for solo projects and early check-ins |
| [Release gate (light)](release-gate.md) | Before every release after the first |
| [Product-type checks](product-type-checks.md) | When your product matches a package; confirms the decisions that are hardest to reverse |

Tick items honestly; "not applicable" needs a reason. Record the outcome in the [Decision Log](../templates/00-foundation/decision-log.md).
