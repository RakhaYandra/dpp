# Planning Readiness: Quick Form

A one-page check for solo projects and early check-ins. The full version is the [Planning Readiness Review](../templates/00-foundation/planning-readiness-review.md).

Answer **yes / no / unknown** and write the single next action for every "no" or "unknown".

| # | Question | Answer | Next action |
|---|---|---|---|
| 1 | Can I state the problem, who has it, and the evidence in two sentences? | | |
| 2 | Do I know how I will measure success (metric, baseline, target, date)? | | |
| 3 | Is the scope written down, including what is *out*? | | |
| 4 | Is the smallest useful release (MVP) defined as a test of a hypothesis? | | |
| 5 | Does every Must requirement have a story and criteria I could test? | | |
| 6 | Do I have measurable targets for speed, availability, security/privacy and accessibility? | | |
| 7 | Can I draw the system's context and main parts, and explain the key choices? | | |
| 8 | Do I know my top five risks and what I will do about each? | | |
| 9 | Do I know how I will test it and what "good enough to release" means? | | |
| 10 | Do I know how I will release it, notice problems, and roll back? | | |
| 11 | Do I know what personal or sensitive data I handle and what rules may apply (checked with someone qualified if needed)? | | |
| 12 | Will I be able to tell, after launch, whether it worked? | | |

**Rule:** build when questions 1–10 are "yes" or the unknowns are consciously accepted and written in the Risk Register. Answers of "unknown" to 1, 2 or 5 are strong reasons to wait.
