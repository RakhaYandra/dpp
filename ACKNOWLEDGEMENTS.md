# Acknowledgements

This framework builds on the shared practice of the product management, requirements engineering, software architecture, quality assurance, security and operations communities. Ideas such as user stories with acceptance criteria, architecture decision records, risk registers, definitions of ready and done, threat modelling, service level objectives and blameless postmortems are widely used industry practices; the templates here express them in original wording and a connected structure.

## Origins

The product requirements template at the centre of this framework was developed from the maintainer's starting PRD templates. Structural ideas from publicly available PRD templates (a Markdown PRD template published on GitHub, a generic narrative PRD outline, an enterprise PRD outline and a document-folder layout sketch) informed the design. **No text from those sources has been copied;** the wording, examples and structure in this repository are original.

If you believe any material here too closely follows another work, please open an issue so it can be corrected.
